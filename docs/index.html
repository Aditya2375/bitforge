KNOW THE BOUNDARY

A core, not a whole computer.

RV32I v2.1, instruction-level, single hart. A flat 64 KiB read/write/execute RAM. No compressed, multiplication, atomics, floating point, CSRs, privilege modes, devices, ELF loader or operating system.

Misaligned accesses trap. FENCE is a no-op in this single-hart environment. ECALL and EBREAK stop precisely at the instruction; use Reset to resume. Other reserved encodings trap as illegal. This is not a cycle-accurate model or an ISA certification.

A run is limited to 10,000 attempted instructions, in short pausable batches. All programs stay in this page. Nothing is uploaded or saved.
